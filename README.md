# J. Shang — Technical Notes

Personal technical blog about AI systems, optimization, and large-scale training.

## Local development

```bash
npm install
npm run dev
```

Production builds are deployed to GitHub Pages by `.github/workflows/deploy.yml`.

The first topic, Muon, is adapted from the public learning repository
[`J-shang/Muon`](https://github.com/J-shang/Muon). Time-sensitive claims keep an
explicit information cutoff and source boundaries.
